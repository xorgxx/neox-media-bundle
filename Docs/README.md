# NeoxMediaBundle — Documentation

Documentation is available in two languages:

- **Français** : [Docs/fr/README.md](fr/README.md)
- **English** : [Docs/en/README.md](en/README.md)

The Media Manager can preview HLS playlists (`.m3u8`): native HLS is used when
available, with optional host-provided `hls.js` support in other browsers.
See the [French](fr/10-media-manager.md#prévisualisation-hls) or
[English](en/10-media-manager.md#hls-preview) Media Manager documentation for
setup details.

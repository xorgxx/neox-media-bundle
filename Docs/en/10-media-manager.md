# 10. Media Manager

Main route:

```text
/admin/media
```

The Media Manager provides:

- responsive grid;
- search;
- filters;
- preview;
- inspector;
- metadata editing;
- deletion;
- multiple upload;
- drag & drop;
- collections;
- modal picker.

## Filters

Main categories:

- all;
- images;
- videos;
- audio;
- documents.

## Inspector

When a media is selected, the inspector allows editing:

- title;
- alternative text;
- description.

It also displays available technical information.
